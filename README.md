# Activity 1: C/C++ Development Environment Setup

## Objective
To set up and verify a C/C++ development environment using Visual Studio Code and GCC.

## Tools Used
- Visual Studio Code
- Microsoft C/C++ extension
- GCC compiler
- G++ compiler
- Windows PowerShell terminal

## Program
The `hello.c` file prints `Hello, World!` to the terminal.

## Verification
- GCC version checked using `gcc --version`.
- G++ version checked using `g++ --version`.
- C program compiled using `gcc hello.c -o hello.exe`.
- Program executed using `.\hello.exe`.

## Problem Faced and Resolution
Both GCC and G++ were available in the terminal, so I verified their versions before compiling and running the C program.

## Result
The development environment was verified, and the Hello World program was tested.
